# Security

This is an experimental local-execution library. Objective functions are ordinary Python
code with the privileges of the process running them. Worker processes are not a sandbox.
Run only objectives and dependencies you trust. Do not load untrusted executable artifacts.

Only the latest development version is maintained. No security support SLA is offered.

Use GitHub's private vulnerability reporting on this repository for sensitive reports.
Do not publish credentials, private data, or exploit details in a public issue. If private
reporting is unavailable, open an issue requesting a private contact without sensitive details.
